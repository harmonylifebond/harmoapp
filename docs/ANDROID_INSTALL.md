# 📱 Android Installation Guide - Harmony Lifebond Tasks\n\n## Quick Start (Easiest Method)\n\n### Option 1: Install via Expo Go (Fastest - 5 minutes)\n\n1. **On your Android phone:**\n   - Open Google Play Store\n   - Search for \"Expo Go\"\n   - Tap \"Install\"\n   - Wait for installation to complete\n\n2. **On your computer:**\n   ```bash\n   cd harmoapp/packages/mobile\n   npm install\n   npm start\n   ```\n\n3. **Scan QR Code:**\n   - Open Expo Go on your phone\n   - Tap \"Scan QR Code\"\n   - Point camera at terminal QR code\n   - App loads automatically!\n\n✅ **Ready to use!** All tasks saved locally.\n\n---\n\n## Option 2: Build APK (Recommended for Production)\n\n### Prerequisites\n- Node.js 16+ installed\n- npm or yarn\n- Android SDK (optional, Expo handles it)\n- 2GB free disk space\n\n### Step 1: Clone Repository\n\n```bash\ngit clone https://github.com/harmonylifebond/harmoapp.git\ncd harmoapp\n```\n\n### Step 2: Install Dependencies\n\n```bash\ncd packages/mobile\nnpm install\n```\n\n### Step 3: Build APK\n\n**Using EAS (Recommended):**\n\n```bash\n# Install EAS CLI\nnpm install -g eas-cli\n\n# Login to Expo account (create free account at expo.dev)\neas login\n\n# Build APK\neas build --platform android --local\n```\n\n**Or using Expo:**\n\n```bash\nnpm run build:android\n```\n\n### Step 4: Download APK\n\n- Build will complete in Expo cloud\n- Visit: https://expo.dev/builds\n- Download the `.apk` file\n- Transfer to your phone via USB cable\n\n### Step 5: Install APK on Phone\n\n1. **Connect phone to computer via USB**\n\n2. **Enable USB Debugging on Android:**\n   - Settings → About Phone\n   - Tap \"Build Number\" 7 times\n   - Go back → Developer Options\n   - Enable \"USB Debugging\"\n\n3. **Install via ADB:**\n   ```bash\n   adb install path/to/app-release.apk\n   ```\n\n   **OR**\n\n4. **Manual Installation:**\n   - Copy APK to phone internal storage\n   - Open File Manager on phone\n   - Find the APK file\n   - Tap to install\n   - Tap \"Install\" when prompted\n\n✅ **Done!** App appears on home screen.\n\n---\n\n## Option 3: Direct Installation (Windows/Mac)\n\n### Using Android Studio\n\n1. **Download Android Studio**\n   - Go to https://developer.android.com/studio\n   - Install Android Studio\n   - Open Android Studio\n\n2. **Build and Install**\n   ```bash\n   cd packages/mobile\n   npm install\n   npm run android\n   ```\n\n3. **Device Setup:**\n   - Connect Android phone via USB\n   - Enable USB Debugging (see above)\n   - Android Studio auto-detects device\n   - App installs automatically!\n\n---\n\n## Troubleshooting\n\n### \"App won't install\"\n- Enable \"Unknown Sources\" in Settings → Security\n- Check Android version (requires 6.0+)\n- Ensure APK is not corrupted (re-download)\n\n### \"USB Debugging not working\"\n- Reinstall Google USB driver\n- Try different USB cable\n- Restart phone and computer\n- Update SDK tools in Android Studio\n\n### \"Build failed\"\n- Clear npm cache: `npm cache clean --force`\n- Delete node_modules: `rm -rf node_modules`\n- Reinstall: `npm install`\n- Try again: `npm run android`\n\n### \"App crashes on startup\"\n- Check internet connection (first launch needs data)\n- Clear app data: Settings → Apps → Harmony Tasks → Clear Data\n- Reinstall app\n- Check device storage (needs 50MB free)\n\n---\n\n## Verifying Installation\n\n✅ App successfully installed when:\n- Icon appears on home screen\n- App opens without crashes\n- Can create and save tasks\n- Tasks persist after closing app\n\n---\n\n## Using the App\n\n### Create a Task\n1. Tap \"Tasks\" tab\n2. Enter task title\n3. Add optional description\n4. Set priority (Low/Medium/High)\n5. Add due date (optional)\n6. Tap \"Add Task\"\n\n### Manage Tasks\n- **Complete**: Tap checkbox ✓\n- **Edit**: Tap pencil icon ✏️\n- **Delete**: Tap trash icon 🗑️\n- **Filter**: Tap All/Active/Completed tabs\n\n### Offline Access\n- App works completely offline\n- All tasks saved on phone\n- No internet required\n- No data sent to servers\n\n---\n\n## System Requirements\n\n| Requirement | Minimum | Recommended |\n|-------------|---------|-------------|\n| Android | 6.0 | 10.0+ |\n| RAM | 2GB | 4GB+ |\n| Storage | 50MB | 100MB+ |\n| Screen | 4.5\" | 5.5\"+ |\n\n---\n\n## Support\n\n**Having issues?**\n\n- 📧 Email: harmonylifebond@gmail.com\n- 📞 Phone: +233 054 601 3582\n- 💬 WhatsApp: +233 054 601 3582\n- 🐛 GitHub Issues: https://github.com/harmonylifebond/harmoapp/issues\n\n---\n\n## Next Steps\n\n1. ✅ Install app\n2. ✅ Create your first task\n3. ✅ Try different features\n4. ✅ Share feedback\n5. ✅ Invite friends to use it\n\n---\n\n**Enjoy your Harmony Lifebond Tasks app! 🎉**\n\nTogether We Rise.
